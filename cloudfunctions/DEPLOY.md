# 云服务接入步骤

以下步骤基于微信开发者工具里的云开发能力来完成。

## 1. 配置环境 ID

打开：

- `config/env.js`

把：

```js
cloudEnvId: "your-cloud-env-id"
```

改成你自己的环境 ID。

环境 ID 可以在微信开发者工具的云开发面板，或者 CloudBase 控制台里看到。CloudBase 官方说明里也明确提到，所有资源都通过环境来管理，每个环境都有全局唯一的环境 ID。

参考：

- [CloudBase 产品概述](https://cloud.tencent.com/document/product/876/18431)

## 2. 开通云开发环境

在微信开发者工具里：

1. 打开当前项目
2. 点击工具栏里的“云开发”
3. 如果还没有环境，按引导创建一个按量计费环境
4. 记下环境 ID

## 3. 创建数据库集合

在云开发控制台：

1. 进入“数据库”
2. 创建集合 `records`

建议先用开发阶段的宽松权限，项目里已经给你准备了一个示例规则文件：

- `cloudfunctions/database.rules.json`

开发阶段可以先允许读写，等我们把用户隔离和分享功能补上，再改成按用户权限收紧。

## 4. 部署云函数

需要部署这 4 个云函数：

- `processAudio`
- `getRecords`
- `getRecordDetail`
- `deleteRecord`

在微信开发者工具里，对每个云函数目录分别执行：

1. 右键函数目录
2. 选择“上传并部署：云端安装依赖”

每个函数都依赖：

- `wx-server-sdk`

项目里已经写在各自的 `package.json` 里了。

## 5. 验证链路

完成后按这个顺序测试：

1. 首页录一段音频
2. 点击“上传并生成倒放版本”
3. 查看是否成功跳到详情页
4. 进入历史页确认是否有记录

## 6. 当前已知状态

现在云函数 `processAudio` 还只是把整条“上传 -> 建记录 -> 返回详情”链路跑通。

也就是说：

- 原音可上传
- 记录可保存
- 历史可查询
- 删除可执行

但“倒放音频”目前还是占位逻辑，还没接真正的云端音频处理。

## 7. 下一步

等你把上面几步走完，我再继续帮你做：

1. 在云函数里接真正的音频倒放
2. 处理 ffmpeg 运行方案
3. 优化记录权限和数据结构
